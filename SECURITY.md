# Политика безопасности

Не публикуйте уязвимости в открытых issue.
Сообщайте через GitHub Security Advisories (вкладка Security → Report a vulnerability).

Мы отвечаем в течение 72 часов и выпускаем исправление в течение 14 дней для критичных проблем.

Поддерживаемые версии: последняя минорная ветка (например 1.8.x).
