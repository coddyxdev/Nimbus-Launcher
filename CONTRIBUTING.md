# Как помочь проекту

1. Создай issue или возьми с меткой `good first issue`.
2. Ветка от `main`: `feat/короткое-имя` или `fix/короткое-имя`.
3. Перед PR: `npm test` и `npm run test:rust`, `cargo fmt`, `cargo clippy -- -D warnings`.
4. Коммиты в стиле Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`).
5. В PR опиши, что и зачем, и приложи скриншот, если менялся интерфейс.
